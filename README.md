# Игротека: ретро-портал игр (igrai-online.vercel.app)

100% статический HTML/CSS/JavaScript. Без поисковой формы, без React/Next.js и без npm-зависимостей. Вёрстка по утверждённому пиксельному макету 2000-х: синие панели, 1px рамки, 1px блики, жёлтые кнопки, две версии шапки, игровой каталог. На мобильном сайт занимает полную ширину экрана.

## Содержимое

- `site/index.html` — главная с шестью карточками.
- `site/games/<slug>/index.html` — **рабочие** Судоку, Косынка, Паук, Маджонг, 2048, Сапёр.
- `site/categories/...` — логические и карточные игры.
- `site/assets/sprites/games/` — 40 индивидуальных наборов PNG, PNG@2x и SVG плюс 32 UI-иконки PNG/SVG.
- `site/assets/sprites/game-icons-atlas.png` и `game-icons.css` — спрайт-атлас (40 иконок).
- `site/icon-kit/` — закрытая от индексации страница просмотра всех **72** иконок (будущие игры **не выданы за рабочие**).
- `site/assets/art/` — элементы точно из согласованного референса, включая превью игр.
- `site/robots.txt`, `site/sitemap.xml`, canonical — `https://igrai-online.vercel.app/`.
- `scripts/` — скрипты воспроизводимой генерации картинок и HTML.

## Деплой на Vercel

1. Содержимое архива загрузить **в корень GitHub-репозитория**.
2. В Vercel: Import Project → репозиторий → Framework `Other`.
3. Build Command оставить пустым, Output Directory — `site`.
4. Привязать к проекту `igrai-online.vercel.app` (если свободен / принадлежит вашему аккаунту).
5. Deploy. Перенаправление 301 **не включено**.

## Как запускать локально

```bash
cd site
python3 -m http.server 8000
```

Откройте `http://localhost:8000` (для ES-модулей игровых движков нужен локальный HTTP-сервер, открытие HTML как file:// может не сработать).

## Перегенерация

```bash
python3 scripts/make_icons.py
python3 scripts/make_ui.py
python3 scripts/crop_reference.py
python3 scripts/build_site.py
```

Внимание: `crop_reference.py` использует оригиналы утверждённых изображений в `/mnt/data`; для расширения сайта **этот скрипт не нужен**, все полученные ассеты уже лежат в `site/assets/art/`. Иконки (`make_icons.py`) и HTML (`build_site.py`) воспроизводятся из исходников без сети.

## iOS / Android

- viewport: `width=device-width,initial-scale=1,viewport-fit=cover`;
- интерактивные элементы имеют увеличенную область касания;
- прокрутка внутри «Паука»/«Сапёра» остаётся локальной, без горизонтального переполнения страницы;
- клавиатурные и touch-сценарии используются уже существующими движками.
